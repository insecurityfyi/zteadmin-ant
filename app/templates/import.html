Columns the importer looks for

  • Time (required): Time, Date Time, Timestamp
  • Rule name: URL Filter Rule, Cloud App Rule, DLP Rule, Firewall Rule, DNS Request Rule, Rule Name, Rule Label
  • User: User, Login, User Name
  • Action: Action, Policy Action
  • Destination: URL, Host, Destination IP, DNS Request
  • Traffic: Sent Bytes, Received Bytes, Total Bytes

Times without a zone are read as UTC. Set the portal's export to UTC, or check the times after import.
