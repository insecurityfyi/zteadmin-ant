Pollers

A poller runs on your local network, polls devices over SNMP, ping and local APIs, and sends results out to this server over HTTPS. Nothing connects in to your network.

Install the new poller

This token is shown once, works once, and expires in 24 hours

On any Linux machine on the LAN (a small VM, an LXC container on Proxmox, or a Raspberry Pi), run this as root. It installs Podman if needed, checks it can reach this server, and starts the poller so it comes back after a reboot:

curl -fsSL https://raw.githubusercontent.com/insecurityfyi/zteadmin-ant/main/deploy/install-poller.sh \
  | sudo bash -s -- --server {{ public_url }} --token {{ new_token }} --name poller-hq-01

Change poller-hq-01 to a name for this site. To update the poller later, run the same curl ... | sudo bash with no arguments. In a Proxmox LXC container, turn on Options > Features > Nesting first.

Or start the container by hand 
podman run -d --name linkwatch-poller --restart=always \
  --cap-add=NET_RAW \
  -e LW_SERVER={{ public_url }} \
  -e LW_ENROLL_TOKEN={{ new_token }} \
  -e LW_POLLER_NAME=poller-hq-01 \
  -v linkwatch-poller:/var/lib/linkwatch \
  ghcr.io/insecurityfyi/linkwatch-poller:latest

Replace podman with docker if that is what the machine has. The first start enrolls the poller and saves its own key in the volume; after that the token is no longer needed. See docs/poller.md for a systemd setup.
