Pollers

A poller runs on your local network, polls devices over SNMP, ping and local APIs, and sends results out to this server over HTTPS. Nothing connects in to your network.

Install the new poller

This token is shown once, works once, and expires in 24 hours

On any Linux machine on the LAN (a small VM, an LXC container on Proxmox, or a Raspberry Pi), run this as root. It installs Podman if needed, checks it can reach this server, and starts the poller so it comes back after a reboot:

curl -fsSL https://raw.githubusercontent.com/insecurityfyi/zteadmin-ant/main/deploy/install-poller.sh \
  | sudo bash -s -- --server {{ public_url }} --token {{ new_token }}{% if not base_name %} --name poller-hq-01{% endif %}

{% if base_name %}It will be named {{ next_name }} (the naming scheme in Settings).{% else %}Change poller-hq-01 to a name for this site, or set a naming scheme in Settings.{% endif %} The script also installs a small update helper on the host, so the poller can be updated from this page later. In a Proxmox LXC container, turn on Options > Features > Nesting first.

Or start the container by hand 
podman run -d --name linkwatch-poller --restart=always \
  --network host --cap-add=NET_RAW \
  -e LW_SERVER={{ public_url }} \
  -e LW_ENROLL_TOKEN={{ new_token }} \
{% if not base_name %}  -e LW_POLLER_NAME=poller-hq-01 \
{% endif %}  -v linkwatch-poller:/var/lib/linkwatch \
  ghcr.io/insecurityfyi/linkwatch-poller:latest

Replace podman with docker if that is what the machine has. The first start enrolls the poller and saves its own key in the volume; after that the token is no longer needed. A poller started by hand has no update helper, so Update on this page can't reach it until you run the install script on it once. See docs/poller.md for a systemd setup.

Factory reset

The poller deletes its key, its buffered results and its update state, and goes back to waiting for an enrollment token, as if it had just been installed. It is then removed from this server and its devices, local APIs and path probes are left without a poller. To use the machine again, press Add poller and run the install command with the new token. This can't be undone.
