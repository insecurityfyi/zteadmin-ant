How it works

Each poller runs mtr on the schedule and sends back every hop's loss, latency (last, average, best, worst) and jitter. Linkwatch looks up the network (AS number) and provider for each public hop and caches it for 30 days.

The alert thresholds above override the built-in Path loss and Path latency rules for this probe. The rule's poll count still applies. A change in the networks the path crosses raises a Path changed networks alert.

Loss at a middle hop that doesn't carry on to later hops usually means that router limits its replies, not that traffic is being dropped. The diagram marks those hops as rate-limited.
