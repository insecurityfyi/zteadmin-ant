Tips

  • A single value usually ends in .0; picking a scalar from a MIB adds it for you.
  • For a table, choose the column (for example ifHCInUcastPkts), not the table or entry.
  • From a shell on the poller: snmpwalk -v2c -c COMMUNITY HOST OID, or snmptranslate -On MIB::name to turn a name into numbers.
  • Alert on it under Alerts > rules: "Health sensor", type "custom OID", sensor name matching this name.
